# 4. Limites et périmètre

La liquidité d’un vault dépend de la qualité de l’inventaire et de la demande sur son token. Un NFT atypique, une collection mal configurée ou une modification des frais peut changer la valeur économique du vault. Le protocole ne supprime pas le risque de marché ni le risque de garde.

Périmètre : lecture documentaire des contrats et fichiers de configuration du dépôt. Aucune installation, compilation, test ou déploiement n’a été effectué ; la suite de tests du dépôt est la référence pour vérifier les scénarios.
