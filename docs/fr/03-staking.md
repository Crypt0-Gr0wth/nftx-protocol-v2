# 3. Staking d’inventaire et récompenses

NFTX ajoute une couche de staking où les unités de vault peuvent être déposées pour recevoir des récompenses. Le gestionnaire calcule les parts selon le temps et les montants engagés, puis distribue les actifs prévus par la configuration.

Cette couche crée une dépendance entre émission de tokens, inventaire et distribution. Les contrats de récompenses doivent empêcher les doubles réclamations et respecter les périodes définies.
